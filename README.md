# 🌱 Viver Bem de Verdade
### Saúde, Comida e Sociedade

Um projeto educativo desenvolvido para incentivar hábitos saudáveis e promover a conscientização sobre alimentação, saúde e qualidade de vida.

---

## 📖 Sobre o projeto

O **Viver Bem de Verdade** é uma plataforma web educativa que apresenta conteúdos sobre alimentação saudável, bem-estar e hábitos do cotidiano de forma simples, interativa e acessível.

O projeto foi desenvolvido como parte da atividade de extensão do curso de **Análise e Desenvolvimento de Sistemas**, com foco em estudantes do 6º ao 9º ano do Ensino Fundamental.

A proposta é mostrar que pequenas escolhas diárias podem contribuir para uma vida mais saudável, incentivando a reflexão sobre alimentação, hidratação, sono, atividades físicas e saúde emocional.

## 🎯 Objetivos

- Incentivar hábitos alimentares mais saudáveis.
- Apresentar informações sobre alimentos e seus benefícios.
- Conscientizar sobre a importância da hidratação.
- Promover o cuidado com a saúde física e emocional.
- Utilizar atividades interativas como ferramenta de aprendizagem.

## ✨ Funcionalidades

- 🏠 **Página inicial:** apresentação do projeto e acesso aos conteúdos.
- 🥗 **Comida & Saúde:** informações sobre alimentação, grupos alimentares e hidratação.
- 💚 **Seu Bem-estar:** conteúdos sobre sono, movimento e saúde emocional.
- 🎮 **Desafios e Quizzes:** atividades interativas para tornar o aprendizado mais divertido.
- 🍓 **Quiz das Frutas:** descubra qual fruta combina com sua personalidade.
- ℹ️ **Sobre:** informações e objetivos do projeto.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entre na pasta do projeto

```bash
cd viver_bem
```

### 3. Crie um ambiente virtual

```bash
python -m venv venv
```

### 4. Ative o ambiente virtual

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Instale o Django

```bash
pip install django
```

### 6. Execute as migrações

```bash
python manage.py migrate
```

### 7. Inicie o servidor

```bash
python manage.py runserver
```

Acesse no navegador:

```text
http://127.0.0.1:8000/
```

## 📱 Responsividade

A plataforma foi pensada para oferecer uma experiência de navegação acessível em diferentes dispositivos, incluindo computadores, tablets e smartphones.

## 🔒 Privacidade e responsabilidade

O projeto possui finalidade exclusivamente educativa. Os conteúdos e atividades não substituem orientações de profissionais de saúde.
